The Nan Design System

One visual language for every screen — Wallet, Marketplace, Payroll, Circles, Careers, and AI — so Nan feels like a single, trustworthy financial operating system, not a collection of features bolted together.

v1.0 Inter + Manrope 8pt grid WCAG AA

Foundations

Spacing — 8pt grid

Every margin, padding, and gap is a multiple of 8px. No exceptions — this alone is what makes unrelated pages feel like the same product.

--sp-1 8px
--sp-2 16px
--sp-3 24px — card padding
--sp-4 32px — large card padding
--sp-5 40px — page margin
--sp-6 48px — section spacing

Button and input height are both fixed at 48px — a tap target big enough for thumbs, and consistent across every form in the product.

Buttons

One primary action per screen, always the gradient. Everything else is secondary or ghost — this is what keeps busy pages (like the dashboard) from feeling like every button is shouting.

Patterns

Empty, loading & error states

An empty screen is an invitation to act, not a dead end — it always offers the next step. Errors say exactly what happened, in Nan's voice, never the system's.
